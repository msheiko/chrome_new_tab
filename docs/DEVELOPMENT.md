# Техническая документация

## Архитектура

Одностраничное Vue 3 приложение, которое Chrome открывает вместо новой вкладки (`chrome_url_overrides.newtab` → `newtab.html`). Бэкенда, фоновых скриптов и `content_scripts` нет. Манифест — Manifest V3 без `permissions`.

```
newtab.html → src/main.js → App.vue
                              ├─ SiteItem.vue   (сайт без группы)
                              └─ GroupItem.vue  (папка)
                                   └─ SiteItem.vue × N (внутри модального окна)
```

### App.vue

Читает `src/data.json` и в computed `items` строит плоский список элементов:

- сайт без `group` → `{ key: url, site }`;
- первый сайт с новым `group` → `{ key: "group:<имя>", group, sites: [site] }`; остальные сайты этой группы добавляются в `sites` того же элемента.

Порядок определяется позицией первого сайта группы. Список выводится через `TransitionGroup` (анимации `site-list-*`). Здесь же заданы CSS-переменные тем (`--bg-color`, `--card-bg`, `--icon-bg`, тени) и тёмная тема через `prefers-color-scheme: dark`.

### SiteItem.vue

Ссылка `<a>` с логотипом и подписью. При ошибке загрузки изображения (`@error`) показывается заглушка: первая буква `title` на градиентном круге. На экранах до 480px карточка занимает всю ширину.

### GroupItem.vue

Кнопка-папка с превью (до 4 уникальных логотипов по `image`) и подписью `Название · N`. По клику открывается оверлей, вынесенный в `body` через `Teleport`, с сеткой `SiteItem`. Закрытие: клик по фону (`@click.self`) или `Esc`. Слушатель `keydown` вешается только пока папка открыта и снимается при размонтировании.

## Данные

`src/data.json` — единственный источник данных, импортируется статически и попадает в бандл. Формат полей описан в [README](../README.md#инструкция-как-добавить-изменить-или-удалить-сайт). Валидации схемы нет, поэтому ошибки (опечатка в пути к логотипу, дубль `url`) проявляются только визуально. Дубль `url` среди одиночных сайтов ломает `key` в `TransitionGroup`.

## Сборка

`vite.config.js`:

- плагин `@vitejs/plugin-vue`;
- вход — `newtab.html`;
- выходные файлы раскладываются в `js/`, `css/`, `assets/` с хешами;
- `cssCodeSplit: false` — один CSS-файл;
- dev-сервер на порту 3000.

Содержимое `public/` копируется в `dist/` как есть, поэтому `public/manifest.json` и `public/icons/` попадают в корень расширения. Пути вида `/img/...` в `data.json` разрешаются относительно корня `dist/`.

## Тема и стили

Цвета — только через CSS-переменные в `App.vue`. Чтобы изменить оформление, правьте переменные `:root` и блок `@media (prefers-color-scheme: dark)`. Стили компонентов `scoped`, кроме глобальных в `App.vue`.

## Частые проблемы

| Симптом | Причина и решение |
|---------|-------------------|
| Новая вкладка не изменилась | Загружена не папка `dist/`, либо расширение не обновлено после сборки |
| Вместо логотипа буква | Неверный путь в `image` или файл не лежит в `public/img/` |
| Сайт не попал в папку | Разное написание `group` (регистр, пробелы) |
